# EstudoLab

Site estático pronto para GitHub Pages.

## Como publicar
1. Crie um repositório no GitHub.
2. Envie todos os arquivos desta pasta mantendo as pastas `assets` e `produtos`.
3. Em Settings > Pages, selecione a branch principal e a pasta `/root`.
4. Salve e aguarde o GitHub Pages publicar.

Os botões dos produtos abrem os PDFs diretamente no navegador.
